# 🏦 Banking Management System

## 📌 Project Description

The **Banking Management System** is a console-based application developed using Java. It helps manage basic banking operations such as creating accounts, depositing money, withdrawing money, transferring funds, checking account balances, and viewing transaction history.

This project uses Object-Oriented Programming (OOP) concepts, exception handling, and file handling to manage and store banking information.

## ✨ Features

- Create a New Bank Account
- View Account Details
- Update Customer Details
- Close Bank Account
- Search Bank Account
- Deposit Money
- Withdraw Money
- Check Account Balance
- Transfer Money Between Accounts
- View Mini Statement
- View Complete Transaction History
- PIN Verification
- Change Account PIN
- Lock and Unlock Accounts
- Check Minimum Balance
- Daily Withdrawal Limit
- Calculate Monthly Interest
- Print Transaction Receipt
- Display All Active Accounts
- Save and Load Account Data Automatically

## 🛠️ Technologies Used

- **Programming Language:** Java
- **Concepts:** Object-Oriented Programming (OOP)
- **Data Storage:** File Handling and Serialization
- **Exception Handling:** Custom Exception Handling
- **Libraries:** Java IO, Collections, BigDecimal, LocalDateTime

## ⚙️ How to Run the Project

**Step 1:** Install Java JDK.

**Step 2:** Clone this repository.

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**Step 3:** Open the project folder in VS Code, IntelliJ IDEA, or Eclipse.

**Step 4:** Compile the Java files.

```bash
javac *.java
```

**Step 5:** Run the application.

```bash
java Main
```

## 💡 Business Rules

- Savings Account Minimum Balance: Rs. 500
- Current Account Minimum Balance: Rs. 0
- Daily Withdrawal Limit: Rs. 10,000
- Monthly Interest Rate: 3% Annual Rate
- Account Number: 6–18 digits
- Mobile Number: 10 digits
- PIN: 4 digits

## 💾 Data Storage

The application uses Java Object Serialization to save account information in a file named `banking_data.dat`.

Account information and transaction details can be loaded when the application starts again.
